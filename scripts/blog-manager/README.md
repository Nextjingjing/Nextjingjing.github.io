# Blog manager

จัดการโพสต์แบบซีรีส์บน Linux ด้วย Go ใช้ standard library เท่านั้น

รันจากโฟลเดอร์โปรเจกต์:

```bash
go run ./scripts/blog-manager/main.go
```

ใช้ **↑ ↓** เลือก แล้ว **Enter** ยืนยัน

1. เลือกโพสต์ เช่น Redis หรือเลือก **สร้างโพสต์ใหม่** แล้วพิมพ์ชื่อ
2. เลือกบทเดิมเพื่อเปิดเขียน หรือเลือก **สร้างบทความใหม่** แล้วพิมพ์ชื่อ
3. โปรแกรมเปิด VS Code ให้เขียนเนื้อหา บันทึกแล้วปิดแท็บไฟล์นั้นเพื่อกลับเมนู

ไม่มีช่องให้กรอก slug โปรแกรมสร้าง URL จากคำภาษาอังกฤษในชื่อ เช่น `อะไรคือ Redis ?` ได้ `redis` และ `What is Redis ?` ได้ `what-is-redis` หากเป็นชื่อไทยล้วนใช้ `post` หรือ `chapter` พร้อมเลขลำดับตามความจำเป็น ชื่อที่แสดงในเว็บยังเป็นชื่อเต็มที่กรอก

โปรแกรมเรียงเลขบท อัปเดตสารบัญ และปุ่มย้อนกลับ/ถัดไปให้ทุกครั้งที่กลับเมนูบทความ บทสุดท้ายมีปุ่มกลับหน้าสารบัญ ถ้าสร้างโพสต์ชื่อเดิมจะเปิดโพสต์ที่มีอยู่ หาก URL ซ้ำกับโพสต์ชื่ออื่นจะเพิ่มเลขท้ายเพื่อไม่ทับไฟล์เดิม กด Enter ว่างตอนถามชื่อเพื่อยกเลิก หรือ Ctrl+C เพื่อออก

ใช้เมนู **แก้บทนำของโพสต์ / ดูสารบัญ** เพื่อเปิดไฟล์โพสต์ ถ้าแก้บทความจากแท็บอื่นขณะโปรแกรมเปิดอยู่ ให้เลือก **รีเฟรชสารบัญจากไฟล์ที่บันทึก**

โปรแกรมใช้ `code --reuse-window --wait` อัตโนมัติ หากต้องการ editor อื่น ตั้ง `EDITOR` เช่น:

```bash
EDITOR=nano go run ./scripts/blog-manager/main.go
```

หากไม่มี editor โปรแกรมจะแสดง path ให้เปิดเอง แล้วกด Enter หลังบันทึก

โครงสร้างไฟล์:

- หน้าโพสต์: `content/post/<slug>/index.md`
- บทความ: `content/blogs/<slug>/<เลขบท>-<slug>/index.md`

URL ใช้ `/post/<slug>/` และ `/blogs/<slug>/<บท>/` ตามโครงสร้างเว็บนี้ สารบัญเดิมใต้ `## สารบัญ` จะถูกแทนจนถึงหัวข้อระดับ 1–2 ถัดไปหรือ shortcode นำทาง แล้วใช้ comment `blog-manager:toc:start/end` เป็นขอบเขตสำหรับการอัปเดตครั้งต่อไป เนื้อหาบทความยังอยู่เหมือนเดิม ส่วน shortcode `page-nav` ถูกสร้างใหม่ตามลำดับบท

อัปเดตสารบัญโดยไม่เข้าเมนู:

```bash
go run ./scripts/blog-manager/main.go sync microservice
```

ตรวจการเปลี่ยนแปลงของเนื้อหาด้วย `git diff` ก่อน commit

ทดสอบ:

```bash
(cd scripts/blog-manager && go test ./... && go vet ./...)
python3 scripts/blog-manager/test_terminal.py
```

การทดสอบ terminal ใช้ไฟล์ชั่วคราวและ editor จำลอง ตรวจปุ่มลูกศร การพิมพ์ชื่อไทย การสร้างไฟล์ การเรียก VS Code และการคืนค่า terminal โดยไม่เปลี่ยนเนื้อหาจริง
